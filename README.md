# 🌟 甜甜的数学冒险 - 布鲁伊主题儿童数学学习

一个专为6-7岁儿童设计的数学学习游戏，采用蓝布鲁伊（Bluey）主题风格，让孩子们在欢乐的游戏中学习数学基础。

## 🎮 游戏特色

### 🎯 主角甜甜
- 可爱的卡通女孩形象
- 标志性的两个冲天小辫子
- 陪伴孩子一起学习成长

### 📚 丰富的数学关卡
- **10个精心设计的关卡**
- 数字认知、基础加减法
- 图形计数、数字排序
- 数学迷宫、接龙游戏
- 逐级递增的难度设计

### ⭐ 星星奖励系统
- 每个关卡最多获得3颗星星
- 收集星星解锁更多内容
- 激励孩子不断挑战

### 🎵 乐乐的音乐商店
- **12首世界名曲**等你解锁
- 贝多芬、莫扎特、柴可夫斯基等大师作品
- 用星星换取美妙音乐
- 乐乐为你唱歌！

### 🏆 成就系统
- **15个成就**等你挑战
- 从"初次冒险"到"全能冠军"
- 记录孩子的每一个进步

## 🎨 设计风格

采用蓝布鲁伊（Bluey）动画的温馨风格：
- 明亮活泼的色彩搭配
- 圆润可爱的UI设计
- 充满童趣的图标和动画
- 友好的用户界面

## 🎯 教育目标

针对6-7岁儿童的数学基础：
- ✅ 数字认知（1-20）
- ✅ 基础加法（20以内）
- ✅ 基础减法（20以内）
- ✅ 图形识别与计数
- ✅ 数字排序与规律
- ✅ 逻辑思维训练

## 🚀 如何使用

1. **直接打开** `index.html` 文件即可开始游戏
2. **选择关卡** - 从简单到困难逐步挑战
3. **完成题目** - 答对获得星星
4. **解锁音乐** - 用星星在音乐商店换取世界名曲
5. **挑战成就** - 完成各种成就获得徽章

## 📱 兼容性

- ✅ 现代浏览器（Chrome, Firefox, Safari, Edge）
- ✅ 响应式设计，支持手机和平板
- ✅ 无需安装，即开即玩

## 🛠️ 技术实现

- **前端**: HTML5 + CSS3 + JavaScript
- **设计**: CSS Grid + Flexbox 响应式布局
- **动画**: CSS3 过渡和关键帧动画
- **图标**: Emoji 表情符号
- **存储**: LocalStorage 本地存储
