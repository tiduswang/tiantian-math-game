# 🌟 甜甜的数学冒险 - 布鲁伊主题儿童数学学习

[![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue)](https://tiduswang.github.io/tiantian-math-game/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![HTML5](https://img.shields.io/badge/HTML5-Game-orange.svg)](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/HTML5)
[![CSS3](https://img.shields.io/badge/CSS3-Animation-blue.svg)](https://developer.mozilla.org/en-US/docs/Web/CSS)
[![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

一个专为6-7岁儿童设计的数学学习游戏，采用蓝布鲁伊（Bluey）主题风格，让孩子们在欢乐的游戏中学习数学基础。

**🎮 立即体验**: [在线试玩](https://tiduswang.github.io/tiantian-math-game/) | **📖 安装指南**: [INSTALL.md](INSTALL.md)

---

## 🎮 游戏特色

### 🎯 主角甜甜
- 可爱的卡通女孩形象
- 标志性的两个冲天小辫子
- 陪伴孩子一起学习成长

### 📚 丰富的数学关卡
- **10个精心设计的关卡**
- 数字认知、基础加减法
- 图形计数、数字排序
- 数学迷宫、接龙游戏
- 逐级递增的难度设计

### ⭐ 星星奖励系统
- 每个关卡最多获得3颗星星
- 收集星星解锁更多内容
- 激励孩子不断挑战

### 🎵 乐乐的音乐商店
- **12首世界名曲**等你解锁
- 贝多芬、莫扎特、柴可夫斯基等大师作品
- 用星星换取美妙音乐
- 乐乐为你唱歌！

### 🏆 成就系统
- **15个成就**等你挑战
- 从"初次冒险"到"全能冠军"
- 记录孩子的每一个进步

---

## 🎨 设计风格

采用蓝布鲁伊（Bluey）动画的温馨风格：
- 明亮活泼的色彩搭配
- 圆润可爱的UI设计
- 充满童趣的图标和动画
- 友好的用户界面
- 蓝天白云、绿色草地背景
- 花朵装饰和飘动云朵动画

---

## 🎯 教育目标

针对6-7岁儿童的数学基础：
- ✅ 数字认知（1-20）
- ✅ 基础加法（20以内）
- ✅ 基础减法（20以内）
- ✅ 图形识别与计数
- ✅ 数字排序与规律
- ✅ 逻辑思维训练

## 🛠️ 技术实现

- **前端**: HTML5 + CSS3 + JavaScript
- **设计**: CSS Grid + Flexbox 响应式布局
- **动画**: CSS3 过渡和关键帧动画
- **图标**: Emoji 表情符号
- **存储**: LocalStorage 本地存储
- **架构**: 单文件，零依赖，即开即用
